# 🎸 A Journey of Joy — Microservices-Based Band Experience

An immersive, highly interactive web ecosystem designed to connect fans with the band's universe in real-time. Moving away from monolithic structures, this project is engineered as a modern, polyglot microservices architecture to ensure high scalability, clean decoupling, and independent deployments.

## 🏗️ Architecture & Microservices Approach

To practice production-grade backend patterns, the platform is split into specialized services:
* **Frontend & Core BFF (Backend-for-Frontend):** Built with semantic HTML5, advanced CSS/Swiper.js animations, and JavaScript (Node.js) to manage user sessions and UI orchestration smoothly.
* **Real-Time Data API (Python):** A high-performance microservice built with Python (FastAPI/Flask) dedicated to fetching, processing, and serving real-time band statistics, system feeds, and external media integrations.

## ✨ Key Features

* **The Intro Curtain:** A custom, responsive splash screen that elegantly slides up upon interaction, inviting the user to "begin a journey of joy" without any harsh page reloads.
* **Dynamic Ep Slideshow:** A fully fluid media carousel powered by Swiper.js, allowing users to naturally swipe or click through episodes with synchronized title updates.
* **Polyglot Microservices:** Demonstrates the practical isolation of services, combining JavaScript's asynchronous power for UI handling and Python's efficiency for data-driven APIs.
* **Clean Architecture:** Built with a strict separation of concerns, featuring independent decoupled service logic and scalable CSS layouts based on Figma prototypes.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox/Transitions), JavaScript (ES6+)
* **Backend Services:** Node.js (JavaScript) & FastAPI/Flask (Python)
* **Libraries:** Swiper.js (for touch/drag physics)
